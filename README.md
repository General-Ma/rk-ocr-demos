# rk-ocr-demos

Repository for OCR demos.

See [the system design](docs/system-design.md) for the planned React and FastAPI
chart review demo.

## Local data

Use the root `data/` directory for local datasets, downloaded files, and other
machine-specific data. Its contents are ignored by Git; only a placeholder is
tracked so the directory is available in a fresh checkout. Do not put secrets
or credentials in the repository.
